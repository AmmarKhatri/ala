# Error catalog

Generated by npm run docs:generate. Do not edit manually.

Typed application errors return MCP isError: true with a structured payload and equivalent JSON text. Unknown exceptions become internal errors without exposing their message or stack.

Retryable means safe to retry unchanged automatically. Current errors require a caller decision or corrective action, so none request automatic retries.

| Code | Default message | Retryable | Recovery |
| --- | --- | --- | --- |
| `invalid_request` | The request is invalid. | false | Correct the request using the advertised input schema. |
| `configuration_invalid` | Configuration is invalid. | false | Correct the reported setting in the environment that starts ALA. |
| `not_found` | The requested item was not found. | false | Check the identifier and select an existing item. |
| `ineligible_target` | The target is not eligible. | false | Select a supported target after reviewing the eligibility details. |
| `spec_invalid` | The function specification is invalid. | false | Correct the FunctionSpec and validate it against the baseline. |
| `toolchain_missing` | A required toolchain is unavailable. | false | Install the required toolchain and run doctor before retrying. |
| `sandbox_unavailable` | The required sandbox is unavailable. | false | Configure an available sandbox backend and retry; do not bypass isolation. |
| `resource_limit` | A resource limit was reached. | false | Review the effective limit and its recovery instructions before retrying. |
| `deadline_exceeded` | The operation exceeded its deadline. | false | Reduce the workload or adjust the reported timeout before retrying. |
| `cancelled` | The operation was cancelled. | false | Start a new operation when ready. |
| `cleanup_incomplete` | Cleanup did not complete. | false | Inspect the reported resources and complete cleanup before starting another operation. |
| `host_unsupported` | This host is unsupported. | false | Use a host listed in the supported platform matrix. |
| `integrity_violation` | An integrity check failed. | false | Stop using the affected artifact and investigate the integrity failure; do not disable the check. |
| `internal` | An internal error occurred. | false | Report the operation and available evidence IDs to the maintainer. |

Payload fields: code, message, retryable, remediation (action, optional setting and restart_required), optional JSON-safe details, and optional evidence_ids.

SDK-owned protocol dispatch and pre-handler argument validation retain SDK error behavior. This catalog covers application errors and handler-output failures.
